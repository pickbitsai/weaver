# Editorial rules

Rules for anyone, human or AI, changing prose in this book. Each exists because the mistake is
common. Add to the feedback log when a rule is broken again.

## Subtract before you add
- **R1. Redundancy means cut, not reword.** If two sentences do the same work, delete the weaker
  one. Don't swap in a synonym.
- **R2. Fix confusion by cutting, not explaining.** A lost reader usually has too much on the page.
- **R3. The author's words survive.** Never replace the author's phrasing with cleaner, flatter
  prose. If structure fights feeling, feeling wins.
- **R4. Images progress; they don't repeat.** An established image, ability or beat must be
  different when it returns. Check what the reader already knows first.

## Verify, don't assume
- **R5. Check a fact before you write it.** Rank, possession, relationship, ability: search the
  manuscript first. A later reveal is not an early fact.
- **R6. Count from the source.** "The file exists" and "the check passed" are not the same as
  the thing being true.
- **R7. A check that has never failed proves nothing.** Break it on purpose once.
- **R8. Derived notes go stale.** After prose changes, re-check anything that quotes or
  summarises it.
- **R9. The latest revision wins.** When changes are combined, confirm every file kept its newest
  edits.
